# 界面设计规范（WarThunderSkinManager）

> 配套功能设计见 `docs/软件功能设计.md`。本文档规定程序界面的视觉语言、设计令牌与组件规范，不含业务代码。
> **本文档为 2.0 版**：按现代设计系统（Design Tokens + Fluent 风格）重写，取代早期简版规范。

---

## 1. 设计原则

- **扁平（Flat）**：纯色块、清晰分隔、充足留白；不使用拟物、重描边与强渐变。
- **克制**：强调色（Primary）只用于**主操作**与**选中态**，避免满屏蓝。
- **一致**：颜色 / 圆角 / 尺寸 / 间距一律取自统一**设计令牌**，不写死魔数。
- **层次**：以「画布底 → 卡片 → 内容」三层表达层次，辅以极轻阴影，而非加粗边框。
- **动效节制**：短（≤ 300ms）、有明确意义；只用透明度 / 位移 / 颜色，不炫技。
- **文案外置**：界面文字不硬编码，全部来自语言文件（见 §7）。

### 2.6 图标

**一套字体**：**Font Awesome 7 Free Solid**（嵌入资源 `Assets/Fonts/fa-solid-900.otf`）。
许可：字体 SIL OFL 1.1、图标 CC BY 4.0——随包保留 `Assets/Fonts/LICENSE-FontAwesome.txt`。
全程序图标统一取自这一套（标题栏 / 导航 / 空态 / 对话框 / 缩略图占位），
**不再使用** Segoe MDL2 Assets 等系统图标字体，也不混用手绘几何或位图图标。

**引用机制（有坑，务必照办）**：嵌入字体的 `pack://…otf#族名`、`./Assets/Fonts/#族名` 等资源形式
**实测全部命中不到**（字体确实在程序集 `g.resources` 里；用一次性 WPF 探针把 7 种形式逐个验证过）。
实际可用的路径是：

1. `IconFontLoader.EnsureLoaded()` 把嵌入副本提取到 `%LOCALAPPDATA%\WarThunderSkinManager\`；
2. 用 **`file:///…/fa-solid-900.otf#Font Awesome 7 Free Solid`** 形式的 `FontFamily`
   （`IconFontLoader.IconFamily`）；
3. `App.OnStartup` 在**主题字典合并之前**注入 `Resources["IconFont"]`——XAML 侧照旧写
   `{StaticResource IconFont}`，无需感知上述细节。

注意 WPF 侧的**族名是 `Font Awesome 7 Free`**（"…Free Solid" 是 GDI+ 里的名字，只能出现在 file URI 的 fragment 上）。
`Themes/ThemeResources.xaml` 里**不要**再定义 `IconFont` 键（字典自己的键会盖住 App 资源里的那个）。
自检有断言守着：字体可解析 + 用到的 18 个字形缺失 = 0。

**状态着色**：图标可以按**状态**换色，但只允许在主题画刷之间切换（四套主题自动一致）：
「WT Live 下载列表」按钮的图标在**有下载 / 导入任务时用主题主色**（`BrushPrimary`，一眼看出在忙），
无任务或全部结束（含失败项）时回到次要色（`BrushTextSecondary`）——状态由
`SkinsViewModel.HasActiveDownloads` 通知，界面侧用 `DataTrigger` 绑定。

**处理中遮罩（长操作的统一反馈）**：任何**要等 1 秒以上**的操作（复制 / 删除 / 导入 / 迁移 / 重建资源库…）
都必须给出"处理中"反馈——否则用户看不到任何变化，会以为没反应而**连点**（重复触发同一个操作）。

- **唯一容器**：`Views/BusyOverlay`（全局唯一实例，宿主放在窗口最上层即可）。可见性由
  `Services/Infrastructure/BusyIndicator` 的引用计数驱动：`using var _ = BusyIndicator.Instance.Begin(Loc["busy.xxx"]);`
  **可嵌套**（内部计数），文案 / 进度 / 取消取**最外层**那次，计数归零才隐藏；
- 形态：半透明遮罩（主题背景色 + `Opacity=0.72`）+ 居中卡片
  （主题表面色 / 圆角 10 / 轻投影）+ **实心弧加载圈**（1.1 秒一圈，`Forever`）+ 一行文案（如"正在复制涂装包…"）；
  按需再加**进度条**（`Scope.Report`）与**取消按钮**（`Begin(text, onCancel)`）；
- **能力可组合**：不定态（只转圈）/ 确定态（再加进度条与 `已迁移 / 总量`、`N / M` 或百分比文案）/
  可取消（卡片内取消按钮）/ 仅文案（无加载圈，用于瞬时切换的短阶段，避免图标闪动）/ 全局独占（见下）；
- **取消语义统一**：凡支持取消的操作，取消入口都在**遮罩上**（常驻可点），并可用 `Esc` 触发
  （`MainWindow.OnPreviewKeyDown` 闸门）；旧实现"关窗即取消"的做法已废弃；
- **加载圈是自绘的"实心弧圆环"**（样式下沉在 `Themes/ThemeResources.xaml` 的 `BusySpinner`，任何窗口可复用）：
  - `Ellipse` 描边走主题主色 + `StrokeDashArray` 只留约 300°——**单位 = 描边宽度的倍数**：
    尺寸 18 / 描边 2 → 中心线半径 `(18-2)/2 = 8`、周长 `2π×8 ≈ 50.27`、÷描边 `≈ 25.13`
    → `20.94 实 + 4.19 空`；加 `StrokeDashCap="Round"` 圆头、整体绕中心旋转；
  - **为什么不用图标字形**：图标字体的 `circle-notch`（`F110`）画出来是**一串短划**（"点串"观感）；
  - **为什么不做渐隐（彗尾）**：曾用 `OpacityMask` 线性渐变做过渐隐版本，**1× 真实尺寸下会让半圈
    看着像断掉**（与其余候选同屏渲染对比后否掉）——加载指示器首先要"一眼认出是在转"，
    因此取实心弧、只留一个干净缺口；
  - 尺寸与描边保持在 18 / 2：与遮罩卡片（`Padding=22,16`）搭配时 1× 下最清楚。
- **进度条同源**：统一走主题里的 `ProgressBar` 样式（与页内进度条同一份，四套主题自动一致）；
- **全局独占（禁用式）**：遮罩可见期间，宿主窗口的其余内容层与**此刻已存在的**其它顶层窗口一并
  `IsEnabled=false`，键盘焦点收到遮罩上——把"互斥"从编码纪律变成机制，封锁范围与模态窗等价。
  遮罩自身保持可交互，**取消入口始终可点**（长任务必须能在遮罩上取消）；
  **busy 期间新开的对话框不禁用**（如导入中途的压缩包密码框，必须可用）；
- **不做延时显示**：这些操作本来就要 1 秒以上，立即可见比"防闪烁"更重要；
- **busy 范围不得跨越模态窗**：进入 `Begin` 前要结束掉待交互的弹窗（如导入的预览确认），
  需要用户输入的对话框只能出现在两次 `Begin` 之间——否则它会被全局独占挡住（`IsEnabled=false`）而无法交互。

**例外：页内持续反馈不并入遮罩**——以下三处是**非阻断 / 多任务 / 局部**反馈，塞进全屏遮罩是**退化**而非统一：

- 应用更新下载：持续数分钟，用户应在下载期间继续使用程序（卡片自带进度 + 速度 + 取消；更新期间的并发
  由 `IsMaintenance` / `SettingsEnabled` 闸门挡住，不靠遮罩）；
- WT Live 下载列表：**多任务可并行**，遮罩会挡住列表本身与各行的重试 / 取消；
- 部件表加载：页面内的局部反馈，遮罩属于过度反应。

这三处的进度条仍用**同一份主题 `ProgressBar` 样式**，"外观同源"已达成，无需并入容器。
此例外**不因遮罩新增取消能力而改变**——它们的差别是"非阻断"，不是"没有取消入口"。

**自绘路径（`Path` / `PathGeometry`）的两条硬规则**（踩过坑）：

1. **几何必须从 <c>0,0</c> 起，或给 `Path` 加 `Stretch="Uniform"` + 显式 `Width/Height`**——
   `Stretch` 默认 `None` 时 Path 按**几何自身坐标系**绘制，几何自带偏移（如勾号 `M 4,9 …`）时
   会叠加居中布局的偏移，图形落在框的**右下角并溢出**（复选框勾号的实际故障）；
2. 只用图标字体能表达的形状优先用字形（见上），自绘路径留给"必须精确控制描边/对齐"的小图形。

**尺寸档**（FA 的墨迹覆盖比 MDL2 大，历史上同位置字号已整体下调一档）：
导航 / 按钮 **14**、行内提示 **15**、对话框图标与缩略图占位 **22**、空状态 **26**、拖入覆盖层 **30**、
标题栏窗口按钮 **12**。

**标题栏窗口按钮**（`TitleBarButton` / `TitleBarCloseButton`）：

- 窗口一律 `WindowStyle="None"` + `WindowChrome` 自绘标题栏，**不用**系统三键；
  四个按钮：置顶 / 最小化 / 最大化 ⇄ 还原 / 关闭，字形写在 `Content`（关闭键写在样式里），
  尺寸 40×28、间距 `2,0`。
- 悬停 = **主题表面色圆角底**（`CornerRadius=6`，120ms 淡入）+ 图标提亮到 `BrushText`；
  按下 = 图标透明度 0.55；关闭键悬停 = **危险色软底 + 危险色图标**。
  悬停底与图标必须是**兄弟节点**（图标放进做透明度动画的容器会连图标一起被隐藏）。
- **置顶**：点一下置顶、再点一下取消；置顶时图标变**主色**以示状态，悬停有提示气泡
  （`app.window.pin`）；仅本次运行有效，不落盘。
- 提示气泡用**主题化 `ToolTip` 样式**（主题表面色底 + 主题边框 + 圆角 6 + 轻投影），不使用系统样式；
  **长提示会自动换行**（样式的 `ContentTemplate` 里带 `TextWrapping="Wrap"`——
  默认字符串内容不换行，会横向溢出气泡外，`MaxWidth` 只约束气泡本身）。
- **仅图标的按钮必须给 `ToolTip`**（没有文字就没有可读入口）；列表行内的小动作优先用
  **`IconButton`**（24×24 紧凑、悬停主题表面色圆角底），文字按钮只在有足够横向空间时使用。

**新增图标时**：优先在同一套字体里找（`Assets/Fonts/` 的字体含 1426 个字形）；
颜色一律走 `Foreground` / 主题画刷（四套主题自动一致）；不要引入位图或系统字形。
新增窗口按钮时同步更新上面的字形表与自检里的码位清单。

## 3. 主题与自定义

- 程序内置**四套配色主题**，设置页「主题」下拉选择：**默认蓝**（§2.1 默认配色）/ **翠绿** / **琥珀** / **深色**（暗色配色）。
- 每个主题是一份**纯颜色字典** `Themes/Theme.<Id>.xaml`（覆盖 §2.1 全部颜色令牌）；画刷与组件样式集中在
  `Themes/ThemeResources.xaml`，按 key 引用颜色令牌。**新增主题** = 新增一份颜色字典 + 在 `Services/Infrastructure/ThemeCatalog.cs` 登记。
- **生效时机：重启**。启动时按 `config.json` 的 `theme` 先合并主题颜色字典、再合并样式字典
  （`StaticResource` 在 XAML 解析时取值，因此不做运行时热切换）；设置页选择后自动保存，并提供「重启程序」按钮。
- **语义色保留**：危险色（Danger 系）在所有主题中保持红色；「已激活」标记在主色为绿的主题（翠绿）下换为蓝色，避免与主色撞色。
- 导出 / 导入主题（复制颜色字典文件）可作为后续扩展。

## 4. 窗口外壳

- **不使用 WPF 自带 Window 操作栏**：采用 `WindowStyle="None"` + `WindowChrome`，自绘标题栏。
  - `WindowChrome` 保留系统缩放边框与阴影，`CaptionHeight=0`、`ResizeBorderThickness=6`。
  - 自定义标题栏高度 36，含：左侧标题文字（绑定窗口 `Title`）、右侧窗口按钮（图标按钮，关闭按钮悬浮变红）。
  - 标题栏区域内按下左键拖动窗口；按钮分别实现最小化 / 最大化（切换）/ 关闭。
- **最大化不遮任务栏**：挂钩 `WM_GETMINMAXINFO`，把最大化边界设为**所在显示器的工作区**
  （多显示器各按所在屏、按物理像素计算）。不修的话自绘外壳最大化会盖住任务栏且四边溢出；最大化时同时去掉窗口 1px 外框（贴边）。
- **拖动最大化窗口 = 还原并继续拖**（标准行为）：光标保持在标题栏上同样的横向比例处；
  **双击标题**切换最大化 / 还原。因此拖动要在 `MouseMove` 过**系统拖动阈值**后才进 `DragMove`
  （在 `MouseDown` 里直接 `DragMove` 会阻塞并吞掉双击）。
- 注意 .NET 10 WPF 下的 DPI 缩放、最大化边界与阴影处理。

## 5. 组件规范

> **过渡动画统一规则**：所有**状态反馈**（悬停 / 按下 / 勾选 / 高亮）的颜色与透明度变化都带过渡——
> **进入 120ms、离开 150ms**（颜色或透明度），按钮按压缩放 0.97（80ms 进入、120ms 回弹）；
> **状态切换**（选中 / 展开）允许直接切换。实现模式 = 触发器保留最终值的 `Setter` + `Enter/ExitActions`
> 里的 `ColorAnimation` / `DoubleAnimation` / `ThicknessAnimation`（开关滑块）。
> ⚠️ 淡出动画的终点必须用 `ColorTransparent` 令牌（随主题取"透明白 / 透明黑"）：
> 写死 `#00FFFFFF` 在深色主题下淡出途中会闪白。
> 注意：动画目标画刷若是共享主题画刷，动画系统会自动克隆，不影响其他控件。

### 5.1 按钮

- **主按钮 `PrimaryButton`**：实心 `PrimaryFill`、白字、高 34、圆角 6、内边距 16。
  - 悬浮 150ms 渐变到 `PrimaryFillHover`；按下变为 `PrimaryFillPressed` 并**缩放至 0.97**（80ms，回弹 120ms）；禁用时整体 50% 透明。
  - ⚠️ 页面默认文字色由**窗口 `Foreground` 继承下发**，**不要**在全局 `TextBlock` 样式里设 `Foreground`——隐式样式优先级高于继承，会把按钮文字强制成深色，压在填充底色上导致不可读。
- **次级按钮 `SecondaryButton`**：白底 + `BorderStrong` 描边、`TextSecondary` 文字。
  - 悬浮底变 `Hover` 且描边转 `Primary`；按压缩放 0.97。
- **导航按钮 `NavButton`**：透明底、`TextSecondary` 文字、高 44、圆角 8、左对齐、图标 + 文字。
  - 悬浮底 `Hover`；**选中态**底 `Surface2`、文字 `Primary`、字重 SemiBold。
- **标题栏按钮**：透明底、固定 46×32；悬浮底 `Hover`（**120ms 颜色过渡**，离开 150ms 回落）、按下图标变淡（0.55）；
  关闭按钮悬浮底 `Danger`（同样带过渡）、图标转白、按下 `DangerPressed`；最大化按钮图标随窗口状态在 `E922` ⇄ 还原 `E923` 间切换。

### 5.2 输入框 `BaseTextBox`

- 高 34、圆角 6、白底、`BorderStrong` 边框、水平内容内边距 6（`Border.Padding` 单次承载，避免文字离边框过远）。
- 悬浮边框转 `BorderFocus`；**聚焦**边框 `BorderFocus` 且描边加粗至 1.5。内容宿主禁用滚动条。

### 5.3 卡片 `Card`

- 白底、1px `Border` 描边、圆角 12、内边距 20、`SnapsToDevicePixels`。
- 阴影：极柔（`BlurRadius=16, ShadowDepth=2, Opacity=0.06`，色 `#0f172a`），仅用于表达层次。
- 页面以卡片分组承载内容（如设置页的「目录配置」「数据表」）。

### 5.4 复选框

- 18×18、圆角 4、白底 `BorderStrong` 描边。
- 选中：底与描边转 `Primary`，显示白色对勾；悬浮描边转 `Primary`。

### 5.5 滚动条

- 细样式，厚 10；轨道 `#EDF1F6` 圆角 4；滑块 `#C7D2DE` 圆角 4，两侧内缩 2。
- 滑块悬浮 `#9AA9BB`、拖拽 `#6B7A8D`；隐藏传统箭头按块（保留翻页）。
- 兼容水平 / 垂直方向。

### 5.6 空状态

- 卡片内：居中/左对齐的**字体图标（30，`TextMuted`）** + **标题（15 SemiBold）** + **说明（13 `TextMuted`）**。

### 5.7 缩略图卡片网格

- **布局**：`WrapPanel`，列数与卡片尺寸由可用宽度计算下发（目标卡片宽 150，间距 12）→ 窗口变化时**列数与卡片尺寸自适应**。
- **卡片**：圆角 10、1px `Border` 描边、缩略图 `UniformToFill`；无预览时中央显示 `TextMuted` 字体图标占位。
- **名称条**：卡片底部**半透明深色**横条（约 70% `#101828`），圆角仅下侧，白字 12、超出省略；**已激活**的包该条改为**半透明绿**（`ActiveStrip` `#CC15803D`）。
- **状态区分**（选中与激活**用不同视觉通道**，避免"既是选中又是激活"时互相遮挡）：
  - **选中** = 外描边 2px **主色蓝**（`PrimaryFill`）；
  - **激活** = 左上角**绿色徽标**「已激活」（`ActiveFill` `#22C55E` 白字）+ **绿色名称条**；卡片网格上方的激活说明文字：**已激活 = 绿**（`Active` `#16A34A`）、**未激活 = 主色蓝**（那只是提示语，不是激活状态）。
- **状态**：选中 = 2px `PrimaryFill` 描边环；悬浮 = 2px `BorderStrong` 描边环。
- **交互**：单击选中、双击打开属性、按住卡片拖到另一张卡片上即**排序**（顺序持久化到各包 `meta.order`）。

### 5.7.1 瀑布流卡片网格（WT Live 浏览）

- **布局**：`MasonryPanel`（`Controls/MasonryPanel.cs`）——卡片**等宽不等高**：列宽由可用宽度算出（目标宽 240、最小 170、最大 360、列数上限 5、间距 16），**卡片高度由内容决定**（缩略图按自身宽高比撑开）。
- **错落规则**：只保证**第一排顶部齐平**；之后每张卡片接在当前**最短的那列**后面（多列等高时取最左列）。与 §5.7 的 `WrapPanel`（整行对齐）是两种观感，不要混用。
- **图片按比例占位（必须）**：缩略图高度 = **图片实际可用宽度** ÷ 图片宽高比（`AspectRatioHeightConverter`）。图片加载完再撑高会让整列重排、滚动位置乱跳——瀑布流最刺眼的抖动就来自这里。
  - 比例只做**异常值护栏**（0.25~6，远宽于正常图片）：占位框比例一旦与实际不符，`UniformToFill` 就会裁边——**任何裁剪都意味着框比例算错了**，不要用"夹取比例"去压制极端图，宁可让那一张卡片真的很高。
  - ⚠️ **宽度必须用图片自己的**（缩略图容器的 `ActualWidth`），**不能直接用列宽**：卡片的内边距 + 1px 描边会让图片比列宽窄（本项目 26px），按列宽算出的框偏高，`UniformToFill` 就会为了铺满高度把图片左右各裁掉约 12%（肉眼可见的裁边）。容器的 `ActualWidth` 首帧为 0，故换算器保留"列宽 − 卡片让出宽度"的兜底值。
- **卡片**：白底 + 1px `Border` 描边 + 圆角 12、内边距 12；缩略图圆角 10（`ClipToBounds` 不认圆角，需在 `SizeChanged` 里设 `RectangleGeometry`，同 §5.7）。**不用 `Card` 样式**：它带阴影，一屏几十张时逐张阴影的开销不值当。
- **缩略图三态**（`WtLiveCardItem.ThumbnailState`）：**加载中 = 加载圈**（`BusySpinner` 缩放到 24、居中）、
  **没有预览图 / 下载解码失败 = 占位图标**（`F03E` image，22 `TextMuted`）、**就绪 = 图片**，三者互斥。
  失败态**不复用加载圈**——一直转会让人以为还在加载（列表一进页面就有几十张图在排队，圈是必要的反馈）。
- **清晰度档位**：设置页「WT Live 卡片图片清晰度」（默认**低清**，见 `Services.WtLiveQualityCatalog`）
  决定下载哪一级 CDN 变体（低清 386px / 中清 800px / 原图），并按**卡片要占的设备像素宽**
  （列宽 DIP × 屏幕缩放）解码——只按 DIP 算，125% / 150% 缩放的屏幕上位图会被再放大一次，看着就是糊的。
  改档只影响之后加载的卡片（重下已显示的 25 张既费流量也压站点），想立刻重载可点页面上的「刷新」。
- **右下角「下载」按钮**（`F019` download，`IconButton` 24×24，ToolTip = `wtlive.card.download`）：
  点它直接打开「从 WT Live 下载」确认窗口，**帖子链接已预填并自动读取**（省掉"复制链接 → 粘贴 → 读取"三步）；
  命令回绑 `DataContext.Skins.OpenWtLiveImportCommand`（`RelativeSource AncestorType=ItemsControl`）+
  `CommandParameter={Binding PostUrl}`——与涂装管理页的入口**共用同一个命令**（不传参数 = 空白打开）。
  **没有站内附件的帖子不显示该按钮**（`HasFile=false`，`Visibility` 触发器）：那条路只会得到一句
  "没有可下载的文件"，按钮等于骗人；这类帖子仍可去网页下载后走「导入压缩包」。
  位置在**副标题行右端**（不是压在缩略图上）：该行右侧本来就空着，压图会挡画面、还得新造一层覆盖层样式。
- **状态**：列表为空时居中显示空态（图标 26 `TextMuted` + 标题 15 SemiBold + 说明 13 `TextMuted`）；已有内容时底部按需显示「加载中 / 失败重试 / 已经到底了」，三者互斥。
- **加载方式**：滚动接近底部预取下一页（距底 400px 起触发）；请求**幂等**，加载中 / 已到底 / 失败态重复触发都直接忽略。
- **点击**：整张卡片可点（`Cursor=Hand`，`Border.MouseLeftButtonUp`）→ 打开详情浮窗（§5.7.2）；
  右下角「下载」按钮的点击**不会**顺带打开浮窗（按钮已把鼠标事件标记为 `Handled`）。

#### 5.7.2 详情浮窗（点卡片打开）

- **入口**：点卡片任意位置 → `WtLive.Detail.OpenCommand`（`ViewModels/WtLiveDetailViewModel.cs`）。
- **形态**：**遮罩浮窗**（`Views/WtLiveDetailOverlay.xaml`），开成独立窗口——浏览是"看列表"的延续，
  弹新窗口会让人以为离开了页面；浮窗还能让「下载确认窗 + 全局处理中遮罩」继续压在最上面。
- **层级**：`Grid.Row=1`（**只盖内容区**，标题栏的窗口按钮保持可用）+ `Panel.ZIndex=40`；
  全局处理中遮罩是 50、拖入提示是 0 —— 详情永远在"处理中"之下、页面之上。
- **压暗底**：主题背景色 + `Opacity=0.72`（与 §2.6 处理中遮罩同一配方，四套主题自动一致）；点压暗底 = 关窗。
- **内容**（自上而下）：预览图轮播 → 标题 / 作者 / 文件 / 互动统计 → 正文（只读可复制、限高 110 内滚动）→
  底部动作（左：在浏览器中打开；右：下载 + 关闭）。空的信息行自动收起，不留空行。
- **下载按钮**：走既有的「从 WT Live 下载」确认窗（链接**预填并自动读取**，与卡片按钮同一个命令）；
  **没有站内附件时置灰**，信息区的"文件"行会写明原因（复用 `wtlive.noFile`）。
- **轮播**：**滚轮切换**（`PreviewMouseWheel` 里 `e.Handled = true`，否则会穿透去滚底下的瀑布流）、
  左右箭头按钮、`←` `→` 方向键，三条路都走 `Step()`（**环绕**：末张往后回第一张）；多张时右下角显示
  「滚轮切换 · 2 / 4」。单张时不显示箭头与计数。
- **图片按需加载**：只看当前这张 + 预取下一张，解码宽度 1280（≈ 640 DIP × 200% 缩放）；
  第 0 张先垫**列表已解好的缩略图**（不空窗），原图到了再替换。关窗即清空（原图解码后每张数 MB）。
- **信息分两层**：卡片已有字段**先把浮窗填满、立刻可看**（不等网络），帖子详情拉到后再覆盖更全的
  正文 / 附件 / 统计；详情拉失败只影响补全（给「重试」），卡片那层照常显示。
- **键盘**：`MainWindow.OnPreviewKeyDown` 闸门——浮窗开着时 `Esc` 关窗、`←` `→` 切图并标记 `Handled`，
  **其余按键放行**（正文要能复制、Tab 要能用）；与处理中遮罩"吞掉所有按键"是两套策略，别合并。

### 5.8 开关（Switch）`ToggleSwitch`

- 用于**二选一**的状态切换（如涂装包属性里的 `replace_tex` ⇄ `set_tex` 写入方式）。
- **轨道** 38×20、圆角 10，关 = `BorderStrong`，开 = `PrimaryFill`；**滑块** 14×14 白色圆形，两侧内缩 3。
- 悬浮时轨道不透明度 0.85；**禁用**（不适用时，如该部件选了「无」）不透明度 0.4 且光标为箭头。
- 两侧可配**状态标签**：当前生效的一侧用 `Text` + SemiBold，另一侧用 `TextMuted`（如 `replace_tex [开关] set_tex`）。
- 破坏性/专业性较强的开关，首次使用应弹窗说明含义，用户确认后不再提示（见 `软件功能设计.md` §3.6）。

### 5.9 消息对话框 `MessageDialog`

- 程序中**不使用系统 `MessageBox`**：所有提示 / 确认统一走 `MessageDialog`（`Services/Infrastructure/MessageDialog.cs` + `Views/MessageDialogWindow.xaml`），保证与主界面同风格。
- **结构**：自绘标题栏（40，可拖动，右侧关闭按钮）→ 内容（图标 26 + 正文 13 `TextSecondary`，超长自动滚动，最大高 330）→ 底部按钮右对齐。
- **尺寸**：宽 460、高度自适应（`SizeToContent=Height`、`MaxHeight=640`），`ResizeMode=NoResize`，`CenterOwner`。
- **图标语义**：`Info` ⓘ / `Question` ?（`Primary`）；`Warning` △（`Warning` 琥珀）；`Danger` ⊘（`Danger` 红）。
- **按钮**：主按钮默认 `PrimaryButton`；**破坏性确认**（删除 / 清除）用 `DangerFillButton`（实心红底白字，`Danger` → 悬浮 `DangerHover` → 按下 `DangerPressed`，含 0.97 按压缩放）；次按钮（取消）`SecondaryButton`；仅提示时隐藏次按钮。
- **文案**：标题缺省「提示」；按钮文案由调用方指定（如「删除」「继续」「清除」「我已了解」），全部来自语言文件。

### 5.10 标签（Tag）

- 用于**只读**的简短分类标注（如涂装包属性里按命名推测的「主体」「法线」）。
- 样式：胶囊（`Tag` 样式：圆角 9、内边距 7×2、字号 11、1px 描边），相邻标签间距 4。
- **文案**：短标签，**不写括号补注**（如「喷气尾焰（马赫环）」→「喷气尾焰」），避免标签撑得太长。
- **色调**（按 `TagTone`）：四种色调**统一为「浅底 + 同色描边 + 深色字」**——
  - **部位 / 功能 = 默认（蓝）**：底 `#DBEAFE` / 边 `#2563EB` / 字 `#1D4ED8`；
  - **纹理（`_n`）= 绿**：底 `#DCFCE7` / 边 `#22C55E` / 字 `#15803D`；
  - **法线（`_c`）= 黄**：底 `#FEF3C7` / 边 `#F59E0B` / 字 `#B45309`；
  - **武器 / 导弹 = 红**（内置武器表确认）：底 `#FEE2E2` / 边 `#EF4444` / 字 `#B91C1C`；
  - **跨载具 = 紫**（候选来自其他载具，§3.6「跨载具复用」）：底 `#EDE9FE` / 边 `#8B5CF6` / 字 `#6D28D9`；
  - 目的是让人在部件列表里**一眼区分**贴图类型与武器部件；受损、环境遮蔽等其余类型沿用默认蓝。
- 与 `ChipButton`（可点击的国家横条胶囊，有选中态）区分：标签**不可交互**，无 hover / 选中态。
- 一行最多 2 个，按重要性从左到右；识别不出就不显示，不占位、不留空标签。

## 6. 动效规范（Motion）

| 场景 | 效果 | 时长 / 曲线 |
|------|------|-------------|
| 窗口加载 | 内容整体淡入（`RootBorder.Opacity` 0→1；**动画内部根容器，不动窗口自身的 `Opacity`**——窗口级 `<1` 会走分层窗口，首帧实色闪烁） | 300ms |
| 页面切换 | 淡入 + 自下方上移 10px | 250ms，`CubicEase EaseOut` |
| 按钮悬浮 | 背景颜色过渡 | 150ms；复原 200ms |
| 按钮按下 | 缩放 0.97 → 1 | 80ms / 120ms |
| 输入框聚焦 | 边框颜色过渡 | 150ms |
| 滚动条滑块 | 颜色变化 | 即时 / 短过渡 |
| 状态提示 | 淡入显示，2.5s 后自动消失 | 200ms |

**原则**：
- 只动**透明度 / 位移 / 颜色 / 缩放**，不动布局尺寸（避免抖动与重排）。
- 页面切换动画由「选中项变化」触发，不依赖初始加载触发（规避 WPF 初始 `EnterActions` 不执行的问题）。
- 动效不得阻塞交互；取消动画后界面仍应完全可用。

## 7. 国际化（界面文案）

- 程序所有**界面文字使用语言文件**，可替换（功能设计 §3.9）。
- 语言文件位于**程序配置目录**下 `lang/<culture>.json`（如 `zh-CN.json`），**JSON**，key **按功能分命名空间**便于扩展：`app.` / `nav.` / `common.` / `settings.` / `skins.` / `vehicles.`。
- 界面通过标记扩展 `{loc:Loc key}` 引用文案；切换语言时界面自动刷新。
- key 缺失时显示 `⟦key⟧` 以暴露未翻译项；不得在界面代码中硬编码中文文案。
- 设置页可**切换界面语言**（内置支持 + `lang/` 目录下的语言文件）；**下拉显示名 = 语言文件内自己声明的
  `app.language.name`**（语言自己写自己，缺失回退语言代码）；切换即时刷新全部 `{loc:Loc}` 绑定，
  **派生文案同步重算**（载具自动译名按新语言检索、国家名重建）。

## 8. 与实现关联

- 语言文件与标记扩展见 `Services/Infrastructure/LocalizationManager.cs` 与 `Localization/LocExtension.cs`。
