## 2. 格式

- **编码**：无 BOM 的 UTF-8（部分工具按 ANSI 打开会显示乱码，属正常现象）；
- **分隔符**：`;`（分号）；字段用**双引号包裹**，引号内 `""` 表示一个引号；
- **表头**：首列 `<ID|readonly|noverify>`，其后为各语言列
  （`<English>` / `<French>` / `<German>` / `<Russian>` / `<Chinese>`（简体）/
  `<TChinese>`（繁体）/ `<Japanese>` …），尾部还有 `<Comments>` / `<max_chars>` 辅助列；
- 行示例：

```
"us_m2a4_1";…;"M2A4";…            ← 短名槽位
"us_m2a4_0";…;"M2A4 (Stuart VI)";… ← 全名槽位
```

## 3. 内容与 id 形态（关键）

表是**本地化键 → 各语言译文**的全量导出，**不是**"每行一辆载具"：

1. **槽位级载具词条**——同一载具有多条，后缀决定含义：
   | 后缀 | 含义 | 示例 |
   |---|---|---|
   | `_1` | **短名**（本程序采用，如 "F-15E"） | `f_15e_1` |
   | `_0` | 全名（"F-15E Strike Eagle"） | `f_15e_0` |
   | `_2` | 类型（"Fighter"） | `f_15e_2` |
   | `_shop` | 商店名 | `f_15e_shop` |

   **没有裸 id 行**——裸载具 id（`f_15e`）须靠追加后缀查表；
2. **带类别前缀的词条**：`ships/uss_cv_immortal_0` 这类，首段是类别；
3. **非载具本地化键**：`air_defence/*`（防空炮阵地）、`killstreak`（连杀奖励）、
   `structures/*` 等——归一化后全表约 4536 个裸 id，其中真正在售载具与
   shop.blkx 高度重合（见 `shop.blkx 参考.md` §3.2 的双向覆盖数据）。

## 4. 解析方法（本程序实现，`VehicleNameTable`）

1. **读表**：`DataTables.Open`——用户表（`<配置目录>/ref/units.csv`）优先，内置嵌入资源兜底；
2. **CSV 解析**：手写逐字符解析器（`;` 分隔、双引号包裹、`""` 转义），只保留首列 + 当前语言列（省内存）；
3. **语言列选择**：界面语言主码 → 列名（`zh-CN` → `<Chinese>`，`zh-TW`/`zh-HK` → `<TChinese>`，
   其他按 `CultureColumns` 映射，无匹配回退 `<English>`）；
4. **译文清理**（源数据脏点较多）：
   - 删**零宽字符**（U+200B 等）：源表在 CJK 字符间夹了大量零宽空格，会把词拆开（`四​联​机​枪`）；
   - **国旗占位符** → 空格：游戏用私用区 / 块元素 / 几何图形等特殊字形在自定义字库里画
     "所属国"小国旗，普通字体下是 `▄` 乱码；
   - 折叠空白（含不换行空格）并去首尾；
5. **查表**（`Lookup`）：字典大小写不敏感，按 **`id_1` → `id_0` → `id` → `id_shop`** 顺序取第一个非空值；
6. **缓存**：按表来源标记（用户表路径 + 写入时间，1 秒 TTL）缓存——用户替换表文件后
   **约 1 秒内生效，无需重启**。

## 5. 用途

- **载具显示名**（§3.7）：优先级 = 用户映射（`mappings/vehicles.json`）→ 本表按界面语言 → 裸 id 回退；
- **与国籍判断正交**：国籍走 shop.blkx（`shop.blkx 参考.md`），译名走本表，互不影响；
- **不是**国籍 / 军种数据源——表里没有归属信息。

## 6. 更新与用户替换

- 首次启动会把内置表**导出**到 `<配置目录>/ref/units.csv` 供用户按需修改；
- 更新策略与语言文件同一思路（§3.9 基线机制）：用户表与**基线**相同（= 没改过）→ 跟随程序
  更新为新版内置表；与基线不同（= 用户改过）→ 保留用户表；
- 替换 / 修改后约 1 秒自动生效（`DataTables.Stamp` 的来源标记机制）；
- 也可在设置页「**更新资源**」（§3.15）一键从上游仓库检查并下载新版本（写入用户表 + 基线）。

## 7. 注意事项

- 双列中文：`<Chinese>` 是简体、`<TChinese>` 是繁体，勿混用（另有 `<HChinese>` 与 `<HJapanese>` 变体列）；
- 译文里的 `№` / 弯引号 / 全角括号是正常文本，清理规则只针对不可见字符与国旗字形，不要扩大化；
- 表条目**多于**实际载具：用它做"载具全量清单"会混入大量非载具键，做清单类需求请以
  shop.blkx 为准。
