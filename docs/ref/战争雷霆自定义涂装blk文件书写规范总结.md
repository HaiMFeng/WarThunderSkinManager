# 战争雷霆自定义涂装 `.blk` 文件书写规范总结

## 一、基本结构

```
name:t="user"

replace_tex {
  from:t="原模型贴图名*"
  to:t="你的贴图文件.dds"
}
```

或

``` 
name:t="user"

set_tex {
  from:t="原模型贴图名*"
  to:t="你的贴图文件.dds"
  param:t="camo_skin_tex"
}
```

- 文件放在 `UserSkins/<载具文件夹>/` 下
- `name:t="user"` 固定开头
- 多模块重复上述结构，分别修改 `from` 和 `to`

---

## 二、`replace_tex` vs `set_tex` 选择

| 场景 | 推荐方式 |
|------|----------|
| 飞机/直升机 | 只用 `replace_tex` |
| 坦克/舰船 可缩放迷彩 | `replace_tex` 替换 `camo_*` 前缀 |
| 坦克/舰船 固定整图 + 保留贴花/做旧 | `set_tex` + `param:t="camo_skin_tex"` |
| 法线 (`_n`)、损伤 (`_dmg`)、附加件、座舱、尾焰 | 只用 `replace_tex` |

**一句话**：除了「坦克/舰船固定迷彩且要保留贴花」之外，全部用 `replace_tex`。

---

## 三、Alpha 通道规则（仅对 `_c` 贴图有效）

- `set_tex`：Alpha 白 = 全局迷彩透明，黑 = 不透明
- `replace_tex`：Alpha 白 = 不透明，黑 = 透明
- 其他贴图（`_n`、`_a` 等）的 Alpha 含义因车型而异，不可套用此规则

---

## 四、只能用 `replace_tex` 的类别

1. 所有载具的法线贴图 `_n` / `_n_dmg`
2. 所有空中载具的全部贴图（包括 `_a`、`_c`、法线、损伤等）
3. 陆地载具的附加组件（侧网、机枪、枪架、爆反、工具箱等）
4. 座舱玻璃、瞄准镜、尾焰、发动机火焰等特殊贴图

---

## 五、常见错误排查

- `from` 没加 `*` → 贴图不加载
- `to` 漏写扩展名 → 不显示
- 文件名大小写/国家前缀错误 → 不匹配
- 模板里引用了载具没有的模块 → 删除对应行
- 飞机误用 `set_tex` 或 `camo_skin_tex` → 无效
- 法线用 `set_tex` → 无效或报错
